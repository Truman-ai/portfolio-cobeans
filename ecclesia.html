Why

개발 취지

찬송가집을 휴대폰으로

PDF 찬송가집을 번호·제목으로 검색하고, 글자 크기와 화면 밝기를 조절해 읽을 수 있게 만들었습니다. 모임 중에는 가사를 슬라이드 화면으로 띄울 수 있습니다.

필요한 정보를 한 앱에

찬송가로 시작해 집회 녹음, 일정, 소식, 차트를 섹션으로 하나씩 더해 한 앱에서 볼 수 있게 했습니다.

개발자 없이 운영

관리자가 앱 안에서 직접 내용을 추가·수정하면 다시 배포하지 않아도 모든 사용자 화면에 바로 반영됩니다.

Features

주요 기능

찬송가

  • 번호·제목으로 찾기
  • 글자 크게·작게, 화면 밝기 전환
  • '띄우기'로 가사를 슬라이드 화면에 표시
  • 음원 듣기, 이전·다음 찬송 이동

일정

  • 월별 달력, 이전·다음 달 이동
  • 오늘 기준으로 보기
  • 일정을 누르면 연결된 주소로 이동

녹음

  • 집회 녹음을 세션별로 정리
  • 하단 플레이어로 이어서 재생
  • 제목으로 찾기, 말씀 텍스트를 슬라이드로 띄우기

차트

  • 차트 이미지 목록
  • 핀치 줌·이동·두 번 탭 확대 뷰어

소식

  • 공지 작성과 링크 첨부
  • YouTube 영상 연결

Operation

운영을 위한 설계

관리자 모드

로그인한 관리자가 각 섹션에서 바로 추가·수정·삭제합니다.

실시간 동기화

Firestore 실시간 구독으로 변경 내용이 바로 보이고, 연결 오류가 나면 잠시 뒤 스스로 다시 연결합니다.

새 콘텐츠 표시

섹션별 마지막 수정 시각과 기기별 확인 시각을 비교해 홈에 "새 찬송가가 있습니다!"를 띄웁니다. 받침에 따라 '이/가'도 맞춥니다.

오프라인 대비

찬송가는 예비 데이터를 내장하고, Firestore 오프라인 캐시를 켜 두었습니다.

앱처럼 설치

웹 앱 매니페스트와 서비스 워커로 홈 화면에 추가해 앱처럼 씁니다.
